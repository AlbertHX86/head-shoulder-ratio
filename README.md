# 头肩比测试器

拍一张正面照，标几个点，看看你是哪种肩。纯前端单文件网页，打开即用。

**在线使用：** https://alberthx86.github.io/head-shoulder-ratio/

## 功能

- **头肩比**：拖动 4 个十字准星到头部最宽处和两侧肩峰，计算 肩宽 ÷ 头宽，并和 ANSUR II（2012 年美军人体测量调查，男 4,082 人 / 女 1,986 人）的分布对比，给出百分位和档位（极窄肩 / 偏窄肩 / 标准肩 / 宽肩 / 超宽肩），可切换男性 / 女性标准。
- **三庭五眼**：拖动 10 个点（发际线、眉心、鼻底、下巴尖 + 眼睛高度的 6 个点），计算三庭比例、五眼比例和综合分数。
- 照片来源：前置摄像头拍照（可镜像），或上传本地照片。
- 支持鼠标和触屏。

## 隐私

所有处理都在本地浏览器完成，照片不会上传到任何服务器。

## 本地运行

直接用浏览器打开 `index.html`。上传照片在本地就能用；摄像头需要 HTTPS 或 `localhost` 环境（在线版本已满足）。

## 说明

纯娱乐向小工具。照片含头发且镜头有透视，结果仅供参考；三庭五眼是传统审美参照，不是医学标准。
